# Golden question set, draft v1 (step 1.2)

Written by the owner with the analysis session on 2026-11-09, from memory and without reading the journal,
so that question wording does not copy the sources. CC-Mac: for every question find the evidence
(file + line ranges), verify or correct the reference answer against the sources, and build `golden.jsonl`.
Where the reference says "to verify" or "to settle from sources", the sources win over this text.

Format additions agreed with the owner:
- `answerable`: "yes" | "partial" | "no". "partial" = the topic appears in the corpus but the question's premise is
  wrong or only part of it is answerable; the expected answer corrects the premise and says what is missing.
- `related`: chunks that SHOULD surface for partial/no questions but do not count as evidence hits. Used in 1.9
  to check that the system classified them correctly instead of answering from them.
- `notes`: what the question is really testing.
